# Жер сілкініс мониторы — демо

Ашық дереккөз (**USGS**, https://earthquake.usgs.gov) негізіндегі жер сілкінісін
бақылау скрипті. Ақышсыз, тіркеусіз, тек Python стандартты кітапханасы.

## Веб-дашбордты сілтеме арқылы ашу

1. `start_server.bat` файлын екі рет басыңыз (терминал терезесі ашылады, жаппаңыз).
2. Сілтемелер:
   - Өз компьютеріңізден: `http://localhost:8000`
   - Телефон/бас құрылғы (сол Wi-Fi-де): `http://192.168.1.104:8000`
     (IP өзгерсе — `ipconfig` командасынан жаңасын алыңыз)
3. Терезені жауып немесе `Ctrl+C` басқанда сервер тоқтайды.

Беттің аяғында автор жазылған: Қыстаубаева Айгул Тулкибаевна — география пәні мұғалімі.

## Қалай іске қосылады

Python орнатылған болуы керек (`python --version` тексеріңіз).

```bat
:: Бір реттік тексеру (әдепкі: Алматы маңы, 500 км, M >= 4.0)
python quake_demo.py --check

:: Әлем бойынша күштілері (соңғы 24 сағат)
python quake_demo.py --check --radius-km 100000 --min-mag 5.0

:: Өз қалаңыз бойынша (ендік/меридиан OpenStreetMap-тен алынады)
python quake_demo.py --check --lat 48.02 --lon 66.93 --radius-km 300 --min-mag 4.0

:: Бақылау режимі: 60 секунд сайын тексеріп, жаңасын айқайлайды + дыбыс
python quake_demo.py --watch --lat 48.02 --lon 66.93 --radius-km 800 --min-mag 4.5 --interval 60
```

## Параметрлер

| Параметр | Мәні | Әдепкі |
|---|---|---|
| `--check` / `--watch` | бір реттік / циклдік режим | `--check` |
| `--lat`, `--lon` | бақылау нүктесі | Алматы (43.238, 76.955) |
| `--radius-km` | радиус, км | 500 |
| `--min-mag` | минималды магнитуда | 4.0 |
| `--interval` | тексеру интервалы, сек | 60 |

## Шектеулер (маңызды)

- Дерек USGS-тен алынады — оқиға болғаннан кейін **1–10 минуттан кейін** ғана
  пайда болады. Бұл «алдын ала ескерту» емес, мониторинг.
- Алдын ала ескерту (early warning) тек сейсмоқұрылғылар желісі тығыз
  аймақтарда жұмыс істейді (АҚШ, Жапония, Мексика, Чили).
- Feed: `all_day` — соңғы 24 сағаттың оқиғалары.
